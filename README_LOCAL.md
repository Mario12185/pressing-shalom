# 🧼 Pressing Shalom - Guide d'Installation Locale

> Plateforme de gestion de pressing et blanchisserie en ligne  
> 🇹🇬 Développé pour le Togo | Next.js 16 + TypeScript + Prisma + SQLite

---

## 📋 Prérequis

| Logiciel | Version minimale | Comment vérifier |
|----------|-----------------|-----------------|
| **Node.js** | 18.x ou 20.x | `node -v` |
| **npm** | 9.x ou + | `npm -v` |
| **PowerShell** | 5.1+ | `$PSVersionTable.PSVersion` |
| **VS Code** (recommandé) | Dernière version | [Code.visualstudio.com](https://code.visualstudio.com) |
